# 🎃 ساختمان شماره ۱۴ — نسخه‌ی گرافیکی (Telegram Mini App)

همان داستان و همان شاخه‌های نسخه‌ی متنی، این بار به‌صورت یک **مینی‌اپ تلگرام**:
صفحه‌ی گرافیکی داخل خود تلگرام، با عکس‌های سینمایی برای هر صحنه، موسیقی محیطی
و افکت صدا (سه ضربه‌ی در، زنگ پایان)، هپتیک، و ذخیره‌ی پیشرفت روی گوشی بازیکن.

- ۳۸ صحنه، ۸ پایان (۶ اصلی + ۲ فرعی) — داده‌ی بازی خودکار از همان `story.py`
  سخت‌سازی‌شده ساخته می‌شود، پس ترتیب شاخه‌ها و شرط پایان‌ها دقیقاً یکی است.
- موتور جاوااسکریپت همان قوانین ضدپرش نسخه‌ی متنی را دارد: هر انتخاب دقیقاً
  یک گام، ایندکس نامعتبر و انتخاب بعد از پایان رد می‌شود، و گالری پایان‌ها دارد.

## ساختار پروژه

```
halloween-miniapp/
├─ bot.py              ← بات لانچر: دکمه‌ی ورود به بازی + ثبت پایان‌ها در چت
├─ story.py            ← منبع یگانه‌ی داستان (همان نسخه‌ی دیباگ‌شده)
├─ convert_story.py    ← ساخت web/story_data.js و .json از story.py
├─ make_audio.py       ← ساخت موسیقی و افکت‌ها با کد (بدون فایل خارجی)
├─ test_miniapp.py     ← تست‌ها: python -m unittest test_miniapp -v
├─ tests/simulate.js   ← شبیه‌سازی موتور در Node: node tests/simulate.js
├─ requirements.txt
└─ web/                ← همین پوشه باید روی هاست HTTPS برود
   ├─ index.html  style.css  app.js  engine.js  story_data.js  story_data.json
   └─ assets/img/ (۴ عکس)   assets/audio/ (موسیقی محیطی + ۳ افکت)
```

## راه‌اندازی (۳ قدم)

### ۱) مینی‌اپ را روی HTTPS بگذار

تلگرام مینی‌اپ را فقط از آدرس **https** باز می‌کند. ساده‌ترین راه با GitHub Pages:

1. در گیت‌هاب یک ریپوی عمومی تازه بساز، مثلاً `halloween-miniapp`
2. **محتوای داخل پوشه‌ی `web/`** را در ریشه‌ی ریپو آپلود کن
   (یعنی `index.html` در ریشه باشد، نه داخل پوشه‌ی web)
3. از `Settings > Pages` گزینه‌ی `Deploy from a branch` → شاخه‌ی `main` و ریشه (`/`) را انتخاب کن
4. چند دقیقه بعد آدرست آماده است: `https://NobodyknowKj.github.io/halloween-miniapp/`

جایگزین‌ها: Netlify Drop، Cloudflare Pages یا Vercel — فقط پوشه‌ی `web/` را بده.

> پیش‌نمایش روی گوشی/کامپیوتر بدون تلگرام: داخل پوشه‌ی `web/` بزن
> `python -m http.server 8000` و برو به `http://localhost:8000` — بازی کامل کار می‌کند.

### ۲) یک بات تازه بساز

در تلگرام به @BotFather دستور `/newbot` بده، یک نام و یوزرنیم انتخاب کن و
توکن را بگیر. **توکن را هیچ‌وقت در چت یا داخل کد نفرست/ننویس.**

### ۳) بات را اجرا کن

کنار `bot.py` یک فایل `.env` بساز:

```
TELEGRAM_BOT_TOKEN=توکن_بات_جدید
WEBAPP_URL=https://NobodyknowKj.github.io/halloween-miniapp/
```

بعد (در Termux):

```bash
cd ~/halloween-miniapp
pip install -r requirements.txt
python bot.py
```

در چت بات `/start` بزن: عکس ساختمان و دو راه ورود می‌آید.
- دکمه‌ی **صفحه‌کلید** (🎃 بازی ساختمان شماره ۱۴): با این وارد شو تا دکمه‌ی
  «ثبت این پایان در چت» داخل بازی کار کند (محدودیت خود تلگرام است).
- دکمه‌ی داخل چت و دکمه‌ی منوی بات هم بازی را باز می‌کنند.

## داخل بازی

- 🔊 دکمه‌ی صدا در نوار بالا: موسیقی محیطی (حلقه‌ی ~۶۱ ثانیه‌ای) + افکت‌ها
- 🦁❤️🧠 آمار زنده با انیمیشن، 🎒 نشان دفترچه‌ی سارا
- 🏆 گالری پایان‌ها از صفحه‌ی شروع و از پایان هر دور
- پیشرفت و پایان‌ها در `localStorage` همان گوشی ذخیره می‌شوند

## توسعه

- داستان را فقط در `story.py` عوض کن، بعد: `python convert_story.py`
- موسیقی/افکت تازه: `python make_audio.py` (به ffmpeg نیاز دارد)
- تست‌ها: `python -m unittest test_miniapp -v` و `node tests/simulate.js`
